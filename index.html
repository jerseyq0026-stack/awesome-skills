How to use

Pick one, then three steps to use it

01

Open the repo, read the README

Each skill repo lists which agents it supports — Claude Code, Codex, Cursor and others — plus install steps.

02

Install it with one command

Most repos support the skills CLI or a plugin marketplace. For the rest, git clone into your local skills folder.

03

Just ask in chat

No commands to memorize: "make me a deck", "write a research report", "cut a vertical video".

Skill directories differ by agent: Claude Code usually uses ~/.claude/skills/. Check each repo for Codex and Cursor setup.
# Universal: the skills CLI
$ npx skills add coreyhaines31/marketingskills
# Claude Code plugin marketplace
> /plugin marketplace add social-media-skills/skills
> /plugin install social-media-skills@social-media-skills
# Manual install
$ git clone <repo-url> ~/.claude/skills/<name>
For readers new to Agent Skills. Emphasize that they can read the README first and decide whether a skill fits before installing anything.
